# Desktop App Assets

This directory contains icons and assets for the OmniBlocks Desktop application.

## Required Files

To complete the desktop app setup, add these icon files:

### Application Icons
- `icon.png` - Main application icon (512x512 PNG)
- `icon.ico` - Windows application icon
- `icon.icns` - macOS application icon

### File Association Icons  
- `sb3-icon.png` - Scratch project file icon (256x256 PNG)
- `sb3-icon.ico` - Windows file association icon
- `sb3-icon.icns` - macOS file association icon

## Icon Generation

You can generate these from the existing OmniBlocks logo:
1. Use the logo from `static/images/512.png` as base
2. Convert to required formats using tools like ImageMagick or online converters
3. Ensure proper sizing for each platform's requirements
